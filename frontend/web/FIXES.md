## Реальная форма создания

Добавлен `POST /api/events`:

```json
{
  "session_id": "form-session-id",
  "request_id": "unique-request-id",
  "type": "task",
  "title": "Подготовить материалы",
  "date": "2026-10-30",
  "time": "18:00",
  "duration_min": null,
  "is_deadline": true,
  "color": "#007788"
}
```

Для задачи дата/время необязательны. Для встречи и напоминания нужны оба поля.
Длительность разрешена встрече, признак дедлайна — задаче. Невалидные поля
отклоняются. Цвет коммитится атомарно с созданием.

Ответ HTTP 200 использует существующий envelope ассистента с `kind`:
`created`, `duplicate`, `confirm` или ошибкой/уточнением. При `confirm` запись
ещё не создана. Отдельное подтверждение формы отправляется в `/api/message`
с той же сессией и новым request_id.

Форма передаёт `ParsedCommand` в существующий core, без NLU-разбора заполненных
полей. Сохранены политики дубликатов, прошедшего времени и конфликтов встреч.
Повтор после потери ответа использует тот же request_id и не создаёт дубль.
Данные формы остаются при ошибке. После успеха запись видна и выбрана в списке.
Общий `ritm/contracts.py`, Event и существующие ответы списка не изменены.

## Layout и визуальная система

Панели имеют независимые состояния: обе открыты, скрыта левая, скрыта правая,
скрыты обе. Колонки пересчитываются без пустых полос и перекрытий. Кнопки
открытия остаются в header. Настройка левой панели переживает перезагрузку.
Список, редактор и диалог сохраняют своё состояние.

После увеличения текста скорректированы отступы и высоты карточек. Длинная
справка редактора перенесена в раскрываемый блок. Удалена декоративная тень
часов; новые градиенты, анимации и глянцевые эффекты не добавлялись.

Композиция, светлые поверхности, фиолетовый системный акцент и умеренные радиусы
сопоставлены с исходными референсами. Выполнена визуальная проверка PNG,
автоматического пиксельного сравнения с вложениями нет. Семантика
[dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)
и [grid](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/grid-template-columns)
сверена с документацией.
