# Тестовый набор планировщика

Скрипт `seed.py` заполняет базу тремя пользователями и их записями. Повторный запуск удаляет этих пользователей (записи уходят каскадом) и создаёт набор заново. Типы и статусы из `backend/sql/001_init.sql` не меняются.

```bash
pip install -r scripts/testdatagen/requirements.txt
python scripts/testdatagen/seed.py
```

Подключение по умолчанию: `postgresql://aivritm:aivritm@127.0.0.1:5435/aivritm`. Другой адрес задаётся переменной `DATABASE_URL`.

Пароль у всех троих один: `testpass`. В `password_hash` лежит SHA-256 от этой строки в hex, без соли. Это метка для тестов, не схема боевой аутентификации.

«Сегодня» — календарный день запуска скрипта в часовом поясе пользователя. Время в таблицах ниже тоже местное. Исключение одно: напоминание «Выпить воду» стоит ровно через час от момента запуска.

У записи никогда не заполнены сразу `due_on` и `due_at`. Пустая ячейка значит `NULL`.

## anna

Основной календарь: все статусы, просроченное, сегодняшний день, будущее и переход через полночь.

### Задачи

| Название | Статус | Срок и время |
|---|---|---|
| Купить молоко | todo | дат нет |
| Сдать отчёт | todo | весь день сегодня. Описание: «Квартальный отчёт в бухгалтерию» |
| Оплатить интернет | todo | весь день вчера, уже просрочена |
| Записаться к врачу | todo | весь день через 7 дней |
| Позвонить клиенту | in_progress | срок сегодня 18:00, напомнить сегодня 17:30 |
| Подготовить слайды | in_progress | блок сегодня 14:00–16:00, срок сегодня 16:00 |
| Разобрать почту | done | весь день 3 дня назад. Описание: «Входящие за неделю» |
| Переезд сервера | cancelled | срок послезавтра 11:00 |
| Черновик статьи | todo | начало завтра 10:00 без конца, срок — весь день завтра |
| Налоги | todo | срок через 30 дней в 12:00, напомнить накануне в 09:00 |

### Встречи

| Название | Статус | Время |
|---|---|---|
| Стендап | scheduled | сегодня 10:00–10:15, напомнить в 09:50 |
| Демо заказчику | scheduled | сегодня 15:00–16:00. Описание: «Показать прототип календаря» |
| Планёрка | done | вчера 11:00–12:00 |
| Созвон с подрядчиком | cancelled | завтра 13:00–13:30 |
| Воркшоп | scheduled | через 3 дня 09:00–13:00 |
| Дежурство | scheduled | сегодня 23:00 — завтра 01:00 |
| Быстрый вопрос | scheduled | завтра 09:00, время конца нет |
| Ретроспектива | done | 5 дней назад 16:00–17:00. Описание: «Команда платформы» |

### Напоминания

| Название | Статус | Когда напомнить |
|---|---|---|
| Выпить воду | pending | через час после запуска |
| Забрать пропуск | pending | завтра 09:00 |
| Позвонить маме | pending | вчера 08:00, время прошло, статус ещё pending |
| Оплатить парковку | done | вчера 19:00 |
| Отменить подписку | cancelled | послезавтра 12:00 |
| Продлить домен | pending | через 14 дней в 08:00 |
