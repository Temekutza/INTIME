# InTime — задачи и выбранная запись

31 октября 2026. Изменён существующий статический frontend, без перехода
на React/Next.js и без изменения API, базы или персональных настроек пользователя.

## Прокрутка и длинные списки

Причина двойной прокрутки: `.records` и `.event-editor` были двумя отдельными
контейнерами с `overflow-y:auto` внутри ограниченной по высоте grid-области.
Редактор также резервировал избыточную высоту формы.

На вкладке задач теперь прокручивается только `#content-grid`. Список и редактор
имеют `overflow:visible`. Редактор закреплён через sticky; если раскрытая форма
выше доступной области, она прокручивается вместе с workspace, затем
закрепляется нижней частью. Действия не перекрывают поля. На коротких экранах
или с длинным названием/раскрытыми пояснениями до нижних действий можно
дойти общей прокруткой, без второго scrollbar. Клавиатура и Tab сохранены.

API возвращает полную коллекцию и не поддерживает offset/cursor. Поэтому
добавлена клиентская пагинация по **40 задач в каждой группе**. Это ограничивает
DOM, но не размер ответа API. Счётчики относятся ко всем задачам. Сортировка,
фильтры, раскрытие групп, страницы и положение при обновлении сохраняются.
Открытие задачи из поиска/создания выбирает содержащую её страницу.
Единственный источник выбранной задачи — `EventEditor.id`; пагинация хранит
только производную информацию, необходимую для определения смены выбора.

## Карточки и редактор

- Строки компактнее, с отдельными отступами, пользовательской цветной полосой,
  мягкой подложкой и названием максимум в две строки. Полный текст — в подсказке
  и редакторе. Нет насыщенной заливки или изменения размеров при выборе.
- Вместо тяжёлой фиолетовой рамки — нейтральная тонкая граница и мягкое изменение
  фона. Mouse selection, keyboard focus и завершение различаются.
- Заголовки групп имеют счётчик и настоящий chevron. Поддерживаются только
  реальные статусы «Созданные» и «Завершённые»; «В процессе» не выдуман.
- Редактор имеет радиус 22px, модальное окно — 24px. Цветная верхняя линия убрана.
  Название 20px, значения полей 14px, подписи 13px, сохранён Segoe UI/system font.
  Фокус названия тонкий и не меняет размеры. Выбор мышью не переводит фокус
  принудительно в textarea; клавиатурное открытие переводит.
- Дублирующая информация и пояснения перенесены в «Дополнительно».
  Сохранение — основное действие, завершение — вторичное.
  **Красная кнопка удаления сохранила цвет #b53748, высоту, радиус и шрифт.**
- DatePicker и TimePicker используют существующие контролируемые компоненты.
  Ошибка центрирования была связана с margin у input внутри wrapper. Отступ
  перенесён на wrapper: оба поля высотой 42px, иконки 17px, зона нажатия 32px.
  Измеренная разница центров иконки и input — 0px на пяти размерах окна.
  Значение не попадает под иконку; локальный контракт времени не изменён.

## Ограничения и решения

Проверен Chromium. Нет новой мобильной версии и проверки Safari/Firefox.
Пагинация клиентская; серверная пагинация потребует согласованного API
и отдельного изменения общей загрузки календаря/счётчиков. Приоритетов и статуса
«В процессе» в контракте нет. Изображение-эталон содержит эти неподдержанные поля,
поэтому полного совпадения содержимого не заявляется.

Решений от Claude для этой правки не требуется. Локальный preview 8765 оставлен
по поручению пользователя тестировать приложение и использует отдельную базу.
