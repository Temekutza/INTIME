# InTime — реконструкция календаря

Дата: 31 октября 2026. Изменён существующий статический интерфейс без
новых зависимостей и изменений backend/API. Работа выполнена основным
агентом, без субагентов. Более ранние незавершённые изменения сохранены.

## Что изменено

- `dashboard.js`: отдельный выбор календарного события по ID; синхронизация
  сводки с EventStore, снятие выбора, очистка после удаления. Явное редактирование
  использует существующий EventEditor в отдельном нативном диалоге.
- `lib/calendar-details.js`: компактная сводка с названием, типом, датой,
  реальным интервалом, статусом и длительностью. Закрытие снимает выбор;
  без выбранного события — строка-подсказка вместо пустого большого редактора.
- `lib/calendar.js`: часы 52px, семь согласованных колонок, отдельные weekday/число,
  круг сегодняшней даты, индикатор времени с подписью на шкале, выбранный блок,
  читаемые короткие записи, независимые полосы пересечений. Весь диапазон
  00:00–24:00 доступен прокруткой. Реальные интервалы не меняются.
- `index.html`, `styles.css`: календарная компоновка, навигация в строке
  заголовка, дата/режим справа, легенда, нижняя сводка около 148px.
  Общая оболочка уплотняется только на вкладке календаря. Другие вкладки
  сохраняют прежние размеры. Кнопка добавления встречи находится справа
  в строке под сеткой; верхняя общая кнопка создания сохранена.
- Тесты: новый `tests/calendar-reconstruction.spec.js`, новый unit-сценарий
  визуальных пересечений; существующие master/colors сценарии адаптированы
  к явному просмотру и модальному редактированию, проверки API сохранены.
- Визуальный контракт: `../docs/ui/calendar-design-contract.md`.

Редактор сохраняет реальные PATCH, персональный цвет, завершение, подтверждение
удаления, обработку ошибок и защиту несохранённого черновика. При открытом
диалоге фон недоступен; перед настройками цветов или переходом в другой раздел
нужно закрыть редактор. В задачах и напоминаниях прежний встроенный редактор
остаётся. Создание, поиск и открытие связанной записи сохранены.

## Ограничения и решения для Claude

- API не предоставляет описание, участников, ссылку/место встречи,
  пользовательскую timezone и совместный доступ. Поля не выдуманы;
  «Поделиться» недоступно с объяснением. Вместо описания показан реальный статус.
- Пользовательские цвета сохранены. У выбранного блока фиолетовый фон
  означает выбор, исходный цвет остаётся на боковой полосе.
- Подписи и плотность чуть крупнее референса ради читаемости; 52px/час
  вместо приблизительно 46px. Длинные названия при плотных пересечениях
  сокращаются; полный текст есть в подсказке и сводке.
- Нет утверждения о визуальном совпадении месяца/года/списка: их референсы
  не предоставлены. Поведение и общие стили проверены.
- Проверен Chromium; Safari/Firefox, мобильный дизайн и смена DST не проверялись.
- Для этой правки решений от Claude не требуется. Для полного содержания
  референса нужна отдельная работа над API по `BACKEND_HANDOFF.md`.

Локальный предварительный сервер доступен на `http://127.0.0.1:8765`.
Он оставлен для пользователя по ранее данному явному поручению тестировать
локально и использует отдельную базу `%TEMP%/aivritm-preview/ritm.db`.
