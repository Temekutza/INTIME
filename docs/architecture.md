# Архитектура и технологии

InTime — один Compose-стек. Браузер открывает интерфейс, nginx отдаёт статику и проксирует `/api` в backend. Backend хранит записи в своём PostgreSQL и для понимания фразы вызывает локальную модель через шлюз.

```text
браузер
   |
   v
nginx :3010          статический интерфейс
   |
   v
FastAPI :8010        /api и /api/v1
   |            \
   v             v
PostgreSQL 16    LiteLLM :4000
:5435                 |
                      v
                 Ollama :11435
                      |
                      v
                 Qwen3-32B на RTX 4090
```

Интерфейс написан на обычном JavaScript, модулями, без React и без сборки. Его отдаёт nginx 1.27. Календарь, список, чат и форма создания ходят в один контракт `/api`: события, пространства, цвета, история и сообщение ассистенту.

Backend — Python 3.12, FastAPI, Pydantic и асинхронный SQLAlchemy. Рядом есть второй контракт `/api/v1`: регистрация, cookie-сессия и прямой доступ к записям. Оба слоя смотрят в одну базу. Схема лежит в `backend/sql` и применяется при первом создании тома Postgres.

Ассистент не вызывает модель напрямую. Запрос идёт в LiteLLM (`ghcr.io/berriai/litellm`, закреплённая версия), дальше в системную Ollama. Снаружи модель называется `qwen3-32b`. Это локальный алиас поверх уже скачанных весов Qwen3-32B Q5_K_M: тот же файл, но шаблон не оставляет ответ внутри блока рассуждений. Ключи приложений, лимиты и учёт токенов хранит отдельный PostgreSQL шлюза, не база планировщика. Master key наружу не отдаётся.

Ollama слушает только `127.0.0.1:11435`, поэтому контейнер LiteLLM работает в сети хоста. Backend из обычной Docker-сети до этого адреса не доходит. Рядом стоит маленький проброс `litellm-docker`: он принимает соединение на адресе docker-моста и передаёт его на `127.0.0.1:4000`.

Распознавание речи вынесено отдельно: GigaAM на порту `9000`. Синтез речи в текущей конфигурации не подключён. Публичный вход один: существующий Caddy на порту `8088` отдаёт сайт, API и Swagger с того же HTTPS-имени. База и шлюз модели снаружи не опубликованы.
