# Тестовый набор планировщика

Скрипт `seed.py` заполняет базу тремя пользователями и их записями. Повторный запуск удаляет этих пользователей (записи, цвета, очередь напоминаний и диалоги уходят каскадом) и создаёт набор заново. Типы и статусы из `backend/sql/001_init.sql` не меняются. Нужны таблицы из `003_interface_fields.sql` и `004_workspaces.sql`. У каждого пользователя при создании появляется пространство «Общее пространство». У anna дополнительно «Работа» и «Личное».

Изолированную тестовую БД `intime_test` (не рабочую `intime`/`aivritm`) пересоздаёт:

```bash
python scripts/testdatagen/apply_schema.py
```

```bash
pip install -r scripts/testdatagen/requirements.txt
python scripts/testdatagen/seed.py
```

Подключение: `DATABASE_URL` или `POSTGRES_*` из `.env`. Пароль в лог не печатается.

Пароль у всех троих один: `testpass`. В `password_hash` лежит SHA-256 от этой строки в hex, без соли. Это метка для тестов, не схема боевой аутентификации.

«Сегодня» — календарный день запуска скрипта в часовом поясе пользователя. Время в таблицах ниже тоже местное. Исключение одно: напоминание «Выпить воду» стоит ровно через час от момента запуска.

У записи никогда не заполнены сразу `due_on` и `due_at`. Пустая ячейка значит `NULL`.

## anna

Основной календарь: все статусы, просроченное, сегодняшний день, будущее и переход через полночь. В каждом пространстве есть задачи, встречи и напоминания, чтобы селектор не открывал пустой экран.

Пространства: «Общее пространство» (по умолчанию), «Работа», «Личное».

| Пространство | Задачи | Встречи | Напоминания |
|---|---|---|---|
| Общее пространство | Купить молоко, Купить хлеб, Протереть пол | Планирование выходных, Поход в кино, Созвон с родителями | Выпить воду, Полить цветы, Вынести мусор |
| Работа | Сдать отчёт, Позвонить клиенту, Подготовить слайды, Переезд сервера | Стендап, Демо заказчику, Планёрка, Созвон с подрядчиком, Воркшоп, Дежурство, Быстрый вопрос, Ретроспектива | Забрать пропуск, Отправить протокол стендапа, Проверить стенд |
| Личное | Оплатить интернет, Записаться к врачу, Забрать куртку из химчистки, Разобрать почту, Черновик статьи, Налоги, Старый черновик | Тренировка, Ужин с друзьями, Прогулка в парке | Позвонить маме, Оплатить парковку, Отменить подписку, Продлить домен |
