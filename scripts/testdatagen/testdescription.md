# Тестовый набор планировщика

Скрипт `seed.py` заполняет базу тремя пользователями и их записями. Повторный запуск удаляет этих пользователей (записи, цвета, очередь напоминаний и диалоги уходят каскадом) и создаёт набор заново. Типы и статусы из `backend/sql/001_init.sql` не меняются. Нужны таблицы из `003_interface_fields.sql` и `004_workspaces.sql`. У каждого пользователя при создании появляется пространство «Общее пространство». У anna дополнительно «Работа» и «Личное».

Изолированную тестовую БД `intime_test` (не рабочую `intime`/`aivritm`) пересоздаёт:

```bash
python scripts/testdatagen/apply_schema.py
```

```bash
pip install -r scripts/testdatagen/requirements.txt
python scripts/testdatagen/seed.py
```

Подключение: `DATABASE_URL` или `POSTGRES_*` из `.env`. Пароль в лог не печатается.

Пароль у всех троих один: `testpass`. В `password_hash` лежит SHA-256 от этой строки в hex, без соли. Это метка для тестов, не схема боевой аутентификации.

«Сегодня» — календарный день запуска скрипта в часовом поясе пользователя. Время в таблицах ниже тоже местное. Исключение одно: напоминание «Выпить воду» стоит ровно через час от момента запуска.

У записи никогда не заполнены сразу `due_on` и `due_at`. Пустая ячейка значит `NULL`.

## anna

Основной календарь: все статусы, просроченное, сегодняшний день, будущее и переход через полночь.

Пространства: «Общее пространство» (по умолчанию), «Работа», «Личное».

| Пространство | Записи |
|---|---|
| Общее пространство | Купить молоко, Выпить воду |
| Работа | Сдать отчёт, Позвонить клиенту, Подготовить слайды, Переезд сервера, Стендап, Демо заказчику, Планёрка, Созвон с подрядчиком, Воркшоп, Дежурство, Быстрый вопрос, Ретроспектива, Забрать пропуск |
| Личное | Оплатить интернет, Записаться к врачу, Разобрать почту, Черновик статьи, Налоги, Старый черновик, Позвонить маме, Оплатить парковку, Отменить подписку, Продлить домен |

### Задачи

| Название | Статус | Срок и время |
|---|---|---|
| Купить молоко | todo | дат нет, приоритет medium |
| Сдать отчёт | todo | весь день сегодня, приоритет urgent, цвет `#be5766`. Описание: «Квартальный отчёт в бухгалтерию» |
| Оплатить интернет | todo | весь день вчера, уже просрочена, приоритет important |
| Записаться к врачу | todo | весь день через 7 дней, приоритет low |
| Позвонить клиенту | in_progress | срок сегодня 18:00, напомнить сегодня 17:30, приоритет urgent |
| Подготовить слайды | in_progress | блок сегодня 14:00–16:00, срок сегодня 16:00 |
| Разобрать почту | done | весь день 3 дня назад, completed_at в 18:00. Описание: «Входящие за неделю» |
| Переезд сервера | cancelled | срок послезавтра 11:00 |
| Черновик статьи | todo | начало завтра 10:00 без конца, срок — весь день завтра |
| Налоги | todo | срок через 30 дней в 12:00, напомнить накануне в 09:00, приоритет important |
| Старый черновик | todo | мягко удалена (`deleted_at`), в списках не показывается |
